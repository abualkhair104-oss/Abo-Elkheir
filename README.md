# متجر أبو الخير للملابس

متجر إلكتروني عربي مبني باستخدام Next.js وReact، ومتصل بـ Supabase لعرض المنتجات والأقسام وإدارة الطلبات. يتضمن الموقع صفحة رئيسية، كتالوجًا، صفحات تفاصيل المنتجات، المفضلة، السلة، ولوحة إدارة.

## الملفات المهمة

- `src/` صفحات الموقع ومكوّناته وواجهات API.
- `supabase/migrations/` ملفات إعداد جداول وسياسات قاعدة البيانات. تُنفّذ بالترتيب الرقمي في مشروع Supabase.
- `public/uploads/` الصور الحالية التي يجب أن تُرفع مع المشروع حتى تظل روابطها متاحة.
- `data/site-content.json` محتوى الموقع المحفوظ محليًا.
- `.env.example` أسماء متغيرات البيئة المطلوبة، بدون مفاتيح حقيقية.

## تشغيل المشروع محليًا على Windows

1. ثبّت Node.js 22 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع.
3. ثبّت الحزم:

   ```powershell
   npm install
   ```

4. أنشئ ملف الإعدادات المحلي:

   ```powershell
   Copy-Item .env.example .env.local
   ```

5. املأ القيم المطلوبة في `.env.local`، ثم شغّل:

   ```powershell
   npm run dev
   ```

6. افتح `http://localhost:3000`.

## إعداد المتغيرات

- `NEXT_PUBLIC_SUPABASE_URL`: رابط مشروع Supabase.
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`: مفتاح النشر العام من Supabase.
- `SUPABASE_SECRET_KEY`: مفتاح سري للخادم فقط. لا تضف إليه بادئة `NEXT_PUBLIC_` ولا تضعه في ملفات الموقع.
- `ADMIN_SESSION_SECRET`: قيمة عشوائية طويلة لحماية جلسة لوحة الإدارة.
- `ADMIN_TEMP_PASSWORD`: كلمة مرور دخول لوحة الإدارة.
- `NEXT_PUBLIC_WHATSAPP_NUMBER`: رقم واتساب المتجر بصيغة دولية، أرقام فقط.
- `NEXT_PUBLIC_SITE_URL`: اختياري. اتركه فارغًا للاعتماد على الدومين الذي يفتح منه الزائر، أو ضع عنوان الموقع المنشور عند ربط دومين خاص.
- `CHECKOUT_ENABLED`: يظل `false` إذا كان تأكيد الطلب عبر واتساب فقط. لا تفعّله إلا بعد تجهيز وحفظ الطلبات في Supabase والتحقق منها.

## رفع المشروع على GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع ومجلد `public/uploads/` وملفات `supabase/migrations/`.
3. لا ترفع `.env.local` أو أي ملف يحتوي كلمات مرور أو مفاتيح. ملف `.gitignore` يستبعد ملفات البيئة و`node_modules` و`.next` تلقائيًا.
4. مجلد `لا ترفع/` يحتوي ملفات Proteus غير المتعلقة بالموقع، ويستبعده `.gitignore` بالكامل.
5. بعد رفع الكود، اربط مستودع GitHub باستضافة تدعم Next.js مثل Vercel، وأضف متغيرات البيئة نفسها من لوحة الاستضافة.

GitHub يحفظ الكود ولا يستضيف تطبيق Next.js وحده. بعد النشر على الاستضافة سيستخدم الموقع الدومين المنشور في روابط المنتجات والصور التي تُرسل على واتساب.

## ملاحظات قبل النشر الفعلي

- الصور الموجودة حاليًا داخل `public/uploads/` يلزم أن تكون ضمن ملفات المستودع لتعمل روابطها بعد النشر.
- رفع الصور ومحتوى الموقع من لوحة الإدارة يُحفَظ حاليًا في ملفات محلية. بيئات الاستضافة مثل Vercel لا تضمن بقاء الملفات التي تُنشأ أثناء التشغيل؛ قبل الاعتماد على رفع الصور أو تعديل المحتوى بعد النشر، يلزم نقل التخزين إلى Supabase Storage وقاعدة البيانات.
- راجع الأسعار والمخزون وبيانات التواصل وسياسات التوصيل والاستبدال قبل استقبال طلبات فعلية.
